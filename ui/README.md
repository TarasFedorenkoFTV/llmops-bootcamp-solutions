# Chat UI (Angular) — готовий

Тонкий чат-інтерфейс: поле вводу, стрічка повідомлень. Дається готовим, студент не змінює.
Ходить у сервіс через dev-proxy `/api` → `service:8080` (`proxy.conf.json`).

Мінімальний Angular standalone-застосунок готовий (`src/app/app.component.ts`) + `Dockerfile`.
Перевірити локально: `npm install && npm start` (це єдина частина стартера, не перевірена збіркою).
