# Reference — W1 (для ментора)

Тут реалізовано лише **перший тиждень** — prompt registry. Решта тижнів поки як TODO
у стартері; еталони на них додамо за потреби.

## Що зроблено (W1)

- Активний system-промпт береться з таблиці `prompts`, а не хардкодом (`GetActivePrompt`).
- У лог кожного запиту пишеться `prompt_version`.
- `GET /prompts` → `[{ name, version, active }]` (консоль показує картку Prompt registry).
- `POST /prompts/{version}/activate` → promote / rollback (робить активною задану версію).
- Схема сідає дві версії: `v2` активна (з «support»), `v1` — щоб показати відкат.

## Запуск і перевірка

```bash
docker compose up --build
```

- Консоль → картка **Prompt registry**: видно v1 (archived) і v2 (active).
- Чат «Як скинути пароль?» → нормальна відповідь (активна v2).
- Відкат на «поганий» промпт: `POST /prompts/v1/activate` → mock починає «не знаю» →
  evals червоніють. Повернув v2 → знову зелено. Це і є демо регресії з реєстру.

## Коли W1 зараховано

Промпт з реєстру, версія в лозі, `/prompts` віддає список, є promote/rollback,
і відкат на поганий промпт валить eval-гейт.
